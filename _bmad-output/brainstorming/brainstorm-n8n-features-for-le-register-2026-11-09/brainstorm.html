Technique 2Constraint Mapping: rock, mist, and trail

Ground rules recorded at the start Le Register = Telegram bot, long polling, SQLite outside the repo, owner-only, append-only journal, outbox, 40 chalets; planned: overlaps, ratings, 08:00 summary, Trello. n8n runs on 127.0.0.1 only.

Only one consumer may poll a bot token (getUpdates), so n8n must not read the Le Register bot's incoming messages; sending via the Bot API is fine, or use a second bot.

Execute Command is off by default in n8n 2.x and n8n only sees files mounted into its volume, so reading the SQLite file needs a deliberate mount or an export.
